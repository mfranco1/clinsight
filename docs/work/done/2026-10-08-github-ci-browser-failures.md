# Fix GitHub CI dashboard screenshot failures

Status: superseded
Owner: Codex
Updated: 2026-10-08

## Goal

Resolve the GitHub CI dashboard screenshot failures while preserving browser workflow coverage.

## Scope

- The original fix added reviewed Linux snapshots, but the user chose to defer Linux screenshot maintenance.
- Keep functional dashboard checks in CI and run pixel comparisons only on macOS locally, where the maintained baseline matches the renderer.
- Retain useful CI failure diagnostics and document the local-only comparison behavior.

## Non-goals

- Application behavior, clinical content, persistence, live AI, dependency upgrades, or backend changes.
- Dependabot PR failures, which involve different dependency trees and require separate investigation.
- Maintaining or comparing Linux screenshot baselines.

- [x] The detailed failure is confirmed from an authenticated job log or a matching Linux reproduction.
- [x] Dashboard functional assertions remain enabled in CI.
- [x] Dashboard pixel comparison runs locally on macOS against its matching reviewed baseline and is skipped in CI.

- [ ] A GitHub CI run on the resulting revision passes both jobs.
