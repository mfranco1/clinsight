# Design

Clinsight supports clinical documentation workflows with browser-local persistence and runtime AI assistance. Preserve clinical meaning, user review, data compatibility, accessible interactions, and responsive behavior when changing the product.

Use these authoritative documents for design details:

- [Architecture](docs/architecture.md): repository ownership, dependency boundaries, patient data flow, AI request flow, and change constraints.
- [Design system](docs/design-system.md): visual conventions, shared UI primitives, interaction, and browser resource lifecycle.
- [Product](docs/product.md): implemented screens and workflows.
- [Data and persistence](docs/data-and-persistence.md): hydration, migrations, attachments, and import/export.
- [AI integration](docs/ai-integration.md): typed gateway/tasks, provider handling, and credential limitations.

Update the relevant topic document with design changes; keep this file as the entry point instead of duplicating their contents.
